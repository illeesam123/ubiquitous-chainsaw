참호전 에셋 매니저

에셋을 선택하세요

우측 상단 핫바에서 이름을 검색하거나 버튼을 누르면 바이옴·상태·무늬별 모양이 표로 나열됩니다.
모양을 클릭하면 다운로드 · 업로드(교체) · 비교를 고를 수 있습니다.

게임이 같은 주소의 다른 탭에서 열려 있으면 교체한 에셋이 즉시 반영됩니다. (npm run editor 로 열면 됩니다)

GitHub 연동

토큰은 이 브라우저의 localStorage 에만 저장되고 GitHub API 외에는 전송되지 않습니다. 이 저장소 하나에만 권한을 준 세분화 토큰(fine-grained)을 권장합니다.

커밋하면 저장소의 assets/sprites/*.svg 가 바뀝니다. 게임 쪽 ☁ 버튼(또는 위 버튼)을 켜 두면 새 커밋의 파일을 바로 읽어 설치 파일 재빌드 없이 적용됩니다.
