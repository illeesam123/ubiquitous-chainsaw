# 참호전 (Trench War) — 데스크톱 패키지

아이소메트릭 참호전 RTS. 기존 단일 HTML(V16)을 모듈로 분리하고 Electron으로 감쌌습니다.

## 실행
```bash
npm install          # electron, electron-builder, playwright
npm start            # 빌드 후 데스크톱 창으로 실행
npm test             # 빌드 + 헤드리스 스모크 테스트
npm run ai:eval      # 고정 시드 AI 대 AI 평가 (옵션: --seeds=6 --seconds=300)
npm run dist         # 설치 파일 생성 (Windows NSIS / macOS dmg / Linux AppImage)
```
브라우저만으로 실행하려면 `npm run build` 후 `dist/index.html`을 열면 됩니다.

## 구조
- `src/NN_이름.js` — 기능별 모듈 (63개). 실행 순서는 `src/MANIFEST.json`이 정합니다.
  - 데이터/생성: constants, util, map-gen, biomes, nature-buildings, special-seeds
  - 시뮬레이션: pathfinding, tasks, units-world, combat, vehicles, medical, demolition, roads, armory-explosives
  - AI: ai-brain, trench-ext, ai-advanced (자경단 대응·위협 지도·역할·수송·전술 학습)
  - 렌더링: render, draw-*, fx, weather, minimap, overlay
  - UI/입력/사운드: ui-state, input, shop-ui, hud, music, sfx
- `assets/music/*.mp3` — BGM (이전엔 base64로 HTML에 내장, 6MB → 230KB 코드 + 외부 파일)
- `tools/build.js` — 모듈을 순서대로 합쳐 `dist/game.js` 생성
- `electron/main.js` — 데스크톱 창 (F11 전체화면, F12 개발자도구)
- `tests/smoke.js` — 게임 시작·시뮬레이션 오류 점검
- `tools/eval-ai.js` — 고정 시드 AI 대 AI 시뮬레이션과 결과 요약

## 벡터(SVG) 스프라이트 (파일 기반)
- 건물·장애물은 `assets/sprites/*.svg` 를 **게임이 직접 읽어** 그립니다. 목록은 `assets/sprites/manifest.js`.
  SVG 파일을 고치면(색, 모양 등) 게임 그림이 그대로 바뀝니다. `assets/sprites/index.html` 을 열면 전체 갤러리를 볼 수 있습니다.
- **기본 디자인은 plain** 하나입니다. 바이옴별 디자인이 있는 건 나무(`tree_swamp_…`, `tree_snow_…`, `tree_arid_…`)뿐이고,
  바이옴 전용 파일이 없으면 자동으로 plain 파일을 씁니다. 새 바이옴 전용 디자인을 만들려면 `src/42_svg-sprites.js`의 `SPR_BIOME`에 종류를 추가하세요.
- 파일 이름 규칙: `종류_바이옴_크기_변형_id_파손단계_이웃_소유_출처_재고.svg`
- 파일에 없는 조합이 생기면 게임이 실행 중에 절차적 그리기 코드로 임시 생성(폴백)합니다.
- `npm run sprites` 는 절차적 그리기 코드에서 SVG를 **다시 생성**해 덮어씁니다(손으로 고친 파일은 사라짐 — 고친 파일은 커밋하고 이 명령은 새 종류를 추가할 때만 쓰세요).
- 병사가 들어 있거나 피격 점멸/박격포 발사 중인 건물은 기존 절차적 그리기로 그립니다. 체력바와 무기고 재고 글자는 위에 덧그립니다.
- 알려진 차이: 나무·의무막사 깃발 흔들림 애니메이션은 정지 상태입니다.
- 최적화가 이루어지지 않았습니다. 중복 적용해야 하는 모양이 많으며, 추후 변경 예정입니다.

## 비주얼 FX (`src/45_visual-fx.js`)
시간대 색조(새벽·정오·황금빛·황혼, 240초 주기), 태양 렌즈 플레어(맑은 낮에만), 세로 그라데이션·비네트, 폭발/포구/화염의 선택적 블룸을 `drawWeatherOverlay` 뒤에 얹습니다. 블룸은 1/4 해상도 발광 버퍼를 사용해 넓은 번짐과 선명한 후광을 합성하고, 렌즈 플레어는 전술 화면을 덜 가리도록 억제했습니다. 언덕 그림자는 경계만 부드럽게 처리하고 접촉 음영은 유지하며, 결과 텍스처는 지형 청크에 포함됩니다. 헤더 ✨ 버튼으로 FX를 끄고 켤 수 있으며 설정은 localStorage(`trench.fx`)에 저장됩니다.

## 에셋(SVG)과 에셋 매니저
- `assets/sprites/*.svg` : 건물·장애물에 더해 **병사(팀×자세×방향), 차량(전차·트럭 ×팀×16방향), 타일(바이옴×종류×음영×무늬), 도로·철로(연결 모양×무늬), 구덩이**가 모두 SVG 파일입니다. 게임은 이 파일을 직접 읽고(`manifest.js` 가 목록), 파일이 없거나 로딩 중이면 기존 절차적 그리기로 폴백합니다.
- 모든 SVG 맨 앞에는 그림 영역 전체에 딱 맞는 **투명 경계 사각형**(`<rect id="bounds" fill-opacity="0">`)이 들어 있어 편집기·미리보기에서 영역이 일정하게 보입니다.
- `npm run sprites` : 게임 그리기 코드에서 SVG·`manifest.js`·`catalog.json` 을 다시 생성합니다 (손으로 고친 파일은 덮어쓰이므로 주의).
- `npm run editor` : 에셋 매니저(http://localhost:5173/editor/) 실행. 우측 상단 핫바에서 에셋 이름을 검색/클릭 → 바이옴·상태·무늬별 표 → 모양 클릭 → **다운로드 / 업로드(교체) / 비교 / 디스크 저장**. 업로드한 그림은 그 에셋 영역에 맞게 자동 보정됩니다(SVG·PNG·JPG·WebP).
- 같은 주소(`/dist/index.html`)의 게임 탭에는 교체본이 **즉시** 반영됩니다(BroadcastChannel + localStorage).
- **GitHub 연동**: 에디터의 GitHub 패널에 저장소·브랜치·토큰(Contents 쓰기 권한)을 넣으면 변경분을 한 커밋으로 푸시합니다. 게임 헤더의 ☁ 버튼(또는 에디터의 "게임이 GitHub 에셋을 읽게 하기")을 켜면 최신 커밋의 SVG 를 raw 주소에서 직접 읽어 재빌드 없이 적용합니다.
- 한계: 참호 타일, 갈대, 수면 물결, 민간인, 헬기 등은 아직 코드로 그립니다. 전차는 포탑이 차체와 정렬됐을 때만 스프라이트(조준·발사 중엔 코드 폴백), 피격 점멸·폭탄 작업 중 병사도 코드 폴백입니다.
- **서버 없이 쓰기**: `npm run editor:html` 이 `dist/asset-manager.html`(카탈로그·SVG 내장 단일 파일)을 만듭니다. GitHub Actions 의 **asset-manager** 산출물로도 내려받을 수 있고, 더블클릭으로 열면 됩니다. (디스크 저장만 제외하고 동일하게 동작)

### 에셋 절감 구조 (v2)
- **병사 몸/팀색 분리**: 몸(다리·머리·헬멧)은 중립 파일, 상의는 *팀색 마스크*(`ubodyt`)로 분리 → 팀·방향마다 만들지 않고 7자세 × 2파일만 사용.
- **총·삽 분리**: `gun_<총기>_side/up/down`, `tool_shovel_side/up/down` 3모양만 두고 각도 보간(트위닝)·좌우반전·레이어 순서(위쪽을 겨누면 몸 뒤)로 사용. 병사에게 `u.gun`(총기칸, 기본 `rifle`)이 있고 `GUNS` 표에 항목을 추가하면 새 총기를 만들 수 있습니다.
- **좌우반전 재사용**: 차량 방향(q↔4−q), 도로 연결(E↔S, W↔N), 타일 무늬(2파일+반전=4종), 나무·바위·상자·잔해의 무늬 3·4번, 울타리/철조망/모래주머니 연결 모양.
- **점령 건물**: 병사가 든 집·헛간·창고·폐허·아파트는 건물 스프라이트 위에 자리별 `occ`(중립) + `occt`(팀색) 오버레이를 얹습니다. 사격 중(총구 화염·피격 점멸)에는 코드 그리기로 폴백.
- **색상 치환형**(`ubodyt`, `occt`, `flagc`)은 에디터에서 따로 분류되며, 마스크의 **회색 명암은 그대로 두고 색상·채도만** 팀 색으로 바뀝니다(`color` 블렌드). 새 마스크는 흰색이 아니라 *중간 회색* 기준으로 명암을 그리세요. 깃발은 기둥 1개 + 천 1장이며 펄럭임은 게임에서 천을 기울임(skew)해 만듭니다.
- **다리**(`bridge`): 육지/물 위 2종. 방향 구분 없이 하나를 사용합니다.
- **에디터 🧩 조합 미리보기**: 병사(몸통+팀색+총기/삽, 조준 각도·앞뒤 레이어), 점령된 건물(건물+점령자), 깃발(기둥+기울인 천)을 게임과 같은 방식으로 합쳐 보여줍니다.
- 에디터의 **ZIP** 버튼: 에셋 종류별로 SVG 전체 + `index.json` + 스프라이트 시트(`sheet.png`/`sheet.json`)를 받습니다. 헤더의 "전체 ZIP"은 모든 SVG(시트 제외).

## 층(layer) 지형 (1단계)
- 높이 단위는 **반층**: 지하 1층=2, 2층=4, **지상 3층=6**, 언덕·산은 최대 +3층(12). `G.lv`(높이), `G.sl`(빗면 방향) — `src/48_layers.js`.
- 타일에는 두께가 있어 앞쪽(+x/+y) 면이 벽으로 보이고, 한 층 차이까지만 **빗면 타일**을 둘 수 있습니다. 빗면은 평평한 타일 그림을 canvas `transform`으로 기울여(skew) 붙이므로 별도 에셋이 필요 없습니다.
- 걷기·차량은 맞닿는 변의 높이 차가 반층 이하일 때만 넘습니다(`stepH`). 절벽은 막힘, 빗면은 통과. 큰 건물·깃발·헬기장은 평지에만 놓입니다.
- 마우스 좌표(`toW`)와 화면 좌표(`toS`)는 고도를 반영합니다. 특수 시드(슈퍼플랫·광산·도시전·해안)와 에셋 추출(`flat:true`)은 평지입니다.
- 바닥 그리기는 16×16 타일 **청크 캐시**로 한 번에 찍습니다(물결만 매 프레임 그림).

### 에셋 전용 출력 · 그림자 · 성능 (층 지형 후속)
- **예비 렌더링 제거**: 게임 안에서는 `assets/sprites` 의 SVG 만으로 그립니다. 파일이 없거나 아직 불러오는 중이면 그리지 않고, 없는 키는 콘솔에 `[에셋 없음]` 으로 한 번만 알립니다. 같은 종류·크기의 가장 비슷한 변형이 있으면 그것으로 대체합니다. 절차적 그리기는 에셋 추출(`npm run sprites`, `REC`)에서만 쓰입니다. 박격포 진지(`mortar`)도 에셋이 생겼습니다.
- **그림자**: 지형 높이로 한 번에 계산(`computeShade`): 꼭짓점마다 태양 방향 차폐(캐스트 섀도) + 접지 그림자를 텍스처 한 장에 담고, 타일은 그 텍스처를 쌍선형 보간해 얹습니다.
- **눈**: 참호·구덩이·물·동굴 입구·다리 칸은 덮지 않고, 투명도가 같은 칸을 한 번에 칠합니다.
- **차량/병사 고도**: 개체를 그리는 동안 고도를 한 값으로 고정해 경사에서 모양이 찌그러지지 않습니다.
- **언덕 가림**: 개체 앞의 높은 타일이 개체를 가리는 부분만 타일 비트맵 캐시에서 잘라 덮습니다.

## WebGL 일괄 그리기 (PixiJS)
- 엔티티 층(병사·차량·건물·나무·깃발·가림 타일)의 `drawImage` 를 `src/49_pixi.js` 가 가로채 **아틀라스 페이지(1024²) + Pixi 스프라이트**로 그린다. 바닥·날씨·FX·UI 는 기존 Canvas 2D 그대로이고, GL 결과는 `drawImage` 한 번으로 합성한다.
- 좌우반전·깃발 기울임·총 회전·알파는 Pixi 변환, 참호 속 병사처럼 `clip()` 으로 잘리는 그림은 UV 를 잘라 같은 모양을 낸다. 덤불·지붕·민간인은 구워서(`glBake`) 아틀라스에 넣고 그림자는 부드러운 방사형 한 장을 늘려 쓴다.
- 항상 켜져 있으며(토글 없음), WebGL 을 쓸 수 없거나 오류가 나면 자동으로 Canvas 경로로 돌아간다.
- 맵 로딩창(`src/50_loading.js`): 시작할 때 맵 전체를 훑으며 에셋을 읽고, 청크 캐시·아틀라스·언덕 가림 타일을 미리 만든다. 로딩 중에는 시뮬레이션이 멈춘다.
- 스프라이트가 캔버스를 오염(tainted)시키면 WebGL 로 올릴 수 없어, Electron 은 `dist` 를 `trench://app/` 스킴으로 서빙한다. 브라우저에서는 `file://` 대신 http 로 여는 것을 권장.
- `vendor/pixi.min.js` (PixiJS 8.23.0) 를 빌드가 `dist/` 로 복사한다.

## 층 2단계: 높이와 사격
- **시선(LOS)**: 사격·전차·민간인 인식은 지형 높이(`simH`)를 따라 시선을 따라가 언덕·벽에 막히면 대상에서 제외된다(눈높이 1.2반층, 목표 0.9반층). 박격포는 곡사라 시선은 보지 않는다.
- **사거리**: 높은 곳에서 쏘면 반층당 +7%(최대 +35%), 낮은 곳에서 쏘면 최대 −25%. 박격포도 높이 보정을 받는다.
- 보기 전환(지하 보기)과 무관하게 시뮬레이션 전용 높이 함수를 쓴다.

## 화면 회전 (90° 단위)
- 헤더 ⟲ ⟳ 버튼 또는 `,` `.` 키. 회전은 **화면 투영만** 바꾸고 게임 상태(좌표·배열)는 건드리지 않는다. 화면 가운데 지점은 회전 후에도 유지된다.
- 구현: `rotXY/unrotXY`(월드↔보기 좌표), `toS/toW/rawS` 가 회전을 반영하고, 칸 단위 그리기(참호·다리·언덕 벽·경사 윗면·그림자·가림 타일)는 **보기 좌표계**로 다시 계산한다. 그리기 순서(깊이)는 `VD`, 칸 순회는 `forTiles` 가 방향에 맞춰 준다. 개체 스프라이트는 같은 그림을 회전한 위치에 찍고, 병사·차량 방향(총·차체)은 `vFace` 로 보기 각도로 바꾼다.
- 도로·이웃 연결 건물(울타리 등)의 연결 비트는 보기 방향 기준으로 구한다. 미니맵은 항상 북쪽 고정(월드 기준)이다.

## 메모리 상한
- 바닥 청크 캔버스: 총 150MB 상한(LRU, 오래 안 쓴 것부터 해제). 새 맵 시작 시 청크·가림 타일 캐시를 모두 해제.
- 가림 타일 비트맵(`TBM`): 600장 상한(가장 오래된 것부터). 아틀라스 페이지: 최대 6장(가득 차면 다음 프레임에 리셋).
- 96×96 기준 장시간 실행에서도 캐시 총량이 늘지 않음(누수 없음, 캐시가 컸던 것이 원인).

## 층 3단계-1: 참호 = 반층 구덩이
- 팀 참호 칸(`G.pit`, `pitSync()`가 매 프레임 `G.trench`에서 파생)은 주변보다 반층(14px) 낮다. 깊이 그림도 반층에 맞춤(기존 8→14px).
- 병사는 구덩이 바닥 높이에 서고(`PIT_PX`), 예전의 임시 '가라앉기' 그림은 제거. 사격 계산(`simH`)에는 `PIT_SIM=.6` 반층이 반영된다(참호 속은 약간 낮아 사거리 보정만 받고, 시선은 막히지 않음).
- 지형 메쉬(언덕 벽·그림자)는 건드리지 않음. 다음: 물이 차는 구덩이, 포탄 구덩이→2층 구멍, 반층 타일·다리 밑 통행.

## 절벽 사다리 (`src/51_ladders.js`)
- 건설 서랍 '참호 개량 → 절벽 사다리'(나무 10·금속 2): 높이 차 1층(2반층) 이상, 4층(8반층) 이하로 맞닿은 두 칸 가운데 절벽 옆 칸을 클릭하면 건설. 위·아래 양쪽에서 쓸 수 있음.
- 길찾기는 사다리로 이어진 두 칸을 이동 가능으로 취급(비용 +4). 병사는 칸 중앙에서 멈춰 절벽을 오르내리며(반층당 0.42초, 최소 0.7초) 높이가 부드럽게 바뀐다.
- 그리기는 개체로 정렬되어 앞쪽 언덕이 가리면 같이 가려진다. 회전과 무관하게 동작.

## 층 3단계-2: 물이 차는 구덩이
- 물(`tt===2`)에 4방향으로 닿은 참호·포탄 구덩이와, 거기에 이어진 구덩이(`G.flood`, `floodPits()`)는 반투명 수면이 차고 병사 이동 속도가 ×0.6. 수면은 구덩이 깊이의 약 58% 높이에 그려지고 발판 널이 비쳐 보인다.
- 날씨·물 효과가 절벽 위에 덮여 그려지던 문제: `hillRepaint()`가 뒤를 가리는 타일(`G.occ`)만 다시 찍고, 가려질 칸의 물결·젖은 땅 효과는 그리지 않는다.

## 디펜스 모드 (`src/52_defense.js`)
- 로비 '모드'에서 선택. 적 기지는 없고, 첫 웨이브는 전투 시작 75초 뒤, 이후 120초마다 맵 가장자리(북동·남동·남서·북서)에서 웨이브가 나타난다. 웨이브는 겹칠 수 있다.
- 웨이브 1~5: 한 방향 5×웨이브 / 6~10: 두 방향 각 4×웨이브 + 부대마다 전차 또는 수송트럭 1 / 11~: 세 방향 각 3×웨이브 + 부대마다 전차·트럭 1, 이후 5웨이브마다 전차 +1(16웨이브 2대, 21웨이브 3대…).
- 웨이브를 전멸시키면 자원 보상(달러 60+28n, 총알 50+18n, 금속 8+4n, 나무 8+3n). 적은 가까운 아군 병사, 없으면 깃발로 진격하고, 트럭은 부대 뒤를 따른다.
- 병사가 전멸하면 종료. 결과 화면의 '맵·진행 저장'(웨이브, 참호·시설, 자원, 병사 수)을 누르면 브라우저에 저장(최대 12개)되고, 로비의 '불러오기'로 이어서 시작(생존 병사 수는 최소 10명으로 복구).

## 지하 자원 · 동굴 (`src/53_ores.js`)
- 동굴은 맵 면적에 비례해 늘리고(96×96 기준 약 6곳, 길이 28~64, 넓은 공동 포함) 철로가 있는 동굴이 2/3.

- 지하 보기에서 광물/수레 칸을 클릭·드래그(땅굴 파기 도구)하면 병사가 지하로 내려가 채굴한다.
- 지상 바위(×0.45)와 덤불(≈×0.5)은 줄이고 나무는 늘렸다.

## 디펜스 모드 조정
- 총알 무한(HUD ∞), 해체·채굴 속도 ×1.8, 언덕 사거리 보정 ×2.6(상한 +70%).

## 총기 종류 · 무기고 교체 (`src/57_weapons.js`)
- 7종: 소총(기본)·새총·권총·돌격소총·저격총·경기관총·대전차포. 수치는 `WEAP` 표 — 탄창(`mag`)·재장전(`reload`)은 병사별(`u.mag`/`u.rl`), 저격총과 경기관총은 날씨 명중률 보정 없음(`wx:0`), 대전차포는 범위 공격(`blast`)·차량 5배(`vdm`). 저격총: 피해 75(병사 체력 150의 50%), 발사 간격 3.8초.
- 구매: 상점(헬기)의 **총기** 칸. 무기고가 있어야 하며 헬기가 내리면 팀 무기 재고(`T.wst`)로 입고된다.
- 무기고 메뉴(🔫 버튼 또는 상점의 버튼): 무기별 병사 수·재고, `[무기] (n명) → [무기] (n명)` 교체 주문. 무기고 16칸 안의 대기 병사가 하나씩 걸어가 헌 무기를 반납하고 새 무기를 받는다. 소총은 재고 무제한.
- 총기 스프라이트: `assets/sprites/gun_<id>_{side,up,down}.svg` (+ `manifest.js`, `tools/export-sprites.js`).

## AI 강화 (`src/58_ai-plus.js`)
기본 지휘(`18_ai-brain.js`)는 그대로 두고, 몇 초마다 보조 판단을 더해 플레이어가 쓰는 수단을 AI 도 쓰게 했다.
- **무기고·총기·수류탄**: 병력 10명 이상이면 무기고 값을 모으며(그 동안 충원 보류) 무기고를 짓고, 성향별 선호(공격형=돌격소총·대전차포, 수비형=경기관총·저격총, 교활형=저격총·권총 …)로 헬기에서 총기와 수류탄을 사서 `swapAdd` 로 병사에게 나눠 준다. 적 차량이 있으면 대전차포를 선호.
- **지형 연결**: 적 본진까지 걸어서 닿는지 BFS 로 확인하고, 막히면 경계에서 적 쪽에 가장 가까운 절벽에 사다리를, 물에는 다리를 놓는다(협곡 맵에서 사다리를 놓아 길을 낸다).
- **동굴·채굴**: 가까운 동굴 입구로 정찰 병사를 보내 지하 지도를 열고, 열린 광석을 캔다. 돈이 마르면 자연 건물을 철거해 수입을 번다.

- 강화는 자원을 즉시 지불하며 구조물 위에 금색 점으로 단계가 표시됩니다. 적 AI도 여유 자원으로 강화합니다.
- 헬기 상점은 보급 / 무장 / 주문 내역 세 묶음으로 접히고, 무기고 메뉴에 투척물 재고가 통합되었습니다.
- AI 는 `18_ai-brain.js` 하나로 통합되었습니다 (약한/공격받는 적 우선 공세, 범위 철거, 적 구조물 해체, 물자 교환).

### 강화 단계별 외형
감시탑(엄폐 감시탑·저격진지), HESCO(위장막 초소·방호진지), 감시포(소이포·SAM 터렛), 구급함(의무 막사·급조 병원), 방벽은 단계마다 모양이 바뀝니다.
스프라이트 키의 마지막 칸에 단계가 들어가며, 그림은 `src/60_struct-looks.js` 의 그리기 코드에서 `node tools/export-levels.js`(먼저 `npm run build`)로 `assets/sprites/` 에 추가로 구워집니다. 기존 에셋은 지우지 않아 손으로 고친 파일이 보존됩니다.

## 수송: 헬리콥터 · 수송트럭
- 병사를 선택한 뒤 **정차한(착륙한) 수송 차량을 클릭**하면 탑승합니다. 이동·비행 중에는 탑승할 수 없습니다.
- 목적지에 도착하면 자동으로 하차하며, 정차 중에는 차량을 선택하고 [주둔 해제 · R] 로 내릴 수 있습니다.
- 수송트럭: 8인승, 보정 없음 (탄약 보급 기능 유지).
- 헬리콥터: 4인승, 건설 시설 → 헬리콥터 (전차급 가격). 이륙·착륙 지연이 있고, 탑승 병사가 대응 사격을 하며 사거리 보정(+4, 날씨 무관)을 받습니다. 비행 중에는 지상 장애물·다른 차량의 영향을 받지 않고 전차·박격포 표적이 되지 않습니다.

## 헬기·민간인·자경단·드롭
- 헬기: `veh|heli|팀|방향`(정지, 날개 접힘) / `veh|heliR|…`(회전, 흐린 원판). 이륙·비행 중엔 회전 모양을 쓰고 높이만큼 위로 띄워 찍는다. `node tools/build.js --sprite-bake && node tools/export-extra.js heli` 로 헬기만, `civ` 로 민간인 몸(`ubodyc|자세`)만 추가로 굽는다(기존 에셋은 지우지 않음).
- 민간인: 병사 몸 에셋(`ubodyc` 중립 몸 + `ubodyt` 마스크)을 회색으로 칠해 재사용, 머리는 모자 없이 머리카락. 항복은 도화선 자세(손 든 모습).
- 자경단: 도시(마을 군집)마다 60% 확률로 4~15명이 한 무리로 생성(검은 옷). 무리가 함께 도시 반경 안을 순찰하고 멀어지면 복귀하며, 접근하는 모든 팀을 공격한다. 50%는 화염병 보유, 총은 소총·권총·돌격소총·저격총·경기관총 중 무작위(대전차포·새총 제외).
- 드롭: 소총 외 무기와 투척물을 든 유닛(또는 자경단)이 죽으면 그 자리에 떨어지고, 어느 팀이든 병사가 닿으면 그 팀 무기고로 들어간다(무기고가 없거나 투척물 칸이 꽉 차면 남는다).

## 구급함 · 항복
- 구급함은 주둔할 수 없는 장애물입니다(병사를 넣을 수 없고, 치료는 항상 같은 속도).
- 항복한 병사·민간인은 사라지지 않고 항복을 받은 팀의 병사가 됩니다. 든 무기는 그대로 갖고, 없으면 소총을 듭니다. (포로 보상금은 없어졌습니다.)

## 자경단 너프 · AI 대응
- 자경단: 도시당 생성 확률 22%(도시전 맵 50%), 전체 30명 상한, 무리 크기는 4~15 중 작은 쪽에 치우침. 체력 40, 사거리 70%, 피해 80%, 명중 70%, 시야 6.5. (`MIL` 상수)
- AI 우회: AI 의 이동 명령은 자경단 활동 구역(도시 반경+7)의 길찾기 비용이 최대 6배가 되어 되도록 돌아간다 (`src/64_ai-advanced.js`, `MILD`).
- AI 소탕: 본진이 안전하고 병력이 무리 수×1.1+2 이상이면(최초 75초 이후, 70초 간격) 통솔 가능한 병력 전체로 가장 가까운 무리를 전멸시킨 뒤 본진으로 복귀한다. 본진이 위협받으면 즉시 중단하고 방어로 전환한다.

## AI 고도화 (`src/64_ai-advanced.js`)
- **위협 지도**: AI 팀은 자기 병사의 시야에 들어온 적의 위치(차량은 가중치 3)를 4×4 칸 격자에 기억하고 매초 3.5% 씩 잊는다. 이동 명령의 길찾기 비용(자경단 구역과 합산, 돌격 부대 제외), 측면 우회 방향(위협이 약한 쪽), 본진으로 위협이 몰릴 때의 사전 배치에 쓴다.
- **병과 역할**: 저격수는 빈 감시탑에 주둔하거나 본진 근처 고지·참호·덤불로, 경기관총수는 적 쪽에 가장 가까운 아군 참호 칸으로 간다(`aiRole`, 건설·원정 차출에서 제외). 원정 부대는 돌격소총·소총수부터 채운다.
- **수송**: 원정 부대가 모이면 대기 중인 수송트럭/헬기에 가까운 병사부터 태워(트럭 8명·헬기 4명) 적 본진 앞 50~70% 지점 중 위협이 약한 곳에 내리고 합류시킨다. 못 탄 병사는 걸어서 합류한다. 상점 구매·건설에서 트럭이 없으면 트럭을, 자금이 520 이상이면 헬기를 짓는다.
- **결과 학습**: 원정이 끝나면 처치/손실 비율로 사용한 전술의 가중치를 곱한다(≥1.3 → ×1.25, <0.8 → ×0.7, 0.35~2.5).
- **구매 반응**: 적이 참호 속에 많으면(35%↑) 저격총·수류탄·포, 노출돼 있으면 경기관총·돌격소총, 저격수·기관총이 많으면 연막, 적 헬기가 있으면 감시포를 더 산다.

## Mafia 시드의 자경단 (`genMafiaMilitia`)
- 아파트마다 거점 무리 7명(저격 2·경기관총 1·돌격소총 2·권총·소총, 절반은 화염병), 감시탑에 저격 2·경기관총 1, 그 외 자연 구조물(집·창고·벙커·기관총 진지 등)의 약 22%에 2~4명의 거점 무리가 붙는다. 거점 무리는 `fixed`(제자리 경계).
- 중심 지구 둘레 11~24칸에 저격수·경기관총 사수 조합 22곳, 도시 순찰 무리(도시의 절반, 5~11명), 들판의 순찰 무리가 팀 수×2곳(최대 7). 순찰 무리는 자기 반경 안에서만 움직이며 본진으로 진군하지 않는다.
- 128×128 맵 기준 약 500~600명(일반 맵은 기존대로 소수). 프레임 비용은 일반 맵과 거의 같다.
- 중앙 마피아 거점(중립 구조물): 강화 모래주머니(방벽) 외벽(±9칸, 사방 3칸 출입구), 모서리 3단계 감시탑 4기 + 안쪽 감시탑 4기, 출입구 양옆 3단계 기관총좌 8기·벙커 4기, 안쪽 L자 방벽, 바깥 철조망, 보급 상자. 감시탑·벙커·기관총좌마다 자경단 거점 무리가 붙는다. (`genMafia`)
- 거점 무리는 자기 구조물(감시탑·아파트·벙커·기관총좌·집·창고 등)에 스스로 들어가고 나온다. 경계(무리 중 한 명이 적 발견)가 올라가면 전원이 안으로 들어가 쏘고(사거리 +1~3, 받는 피해 45% 감소, 정원: 감시탑 2·아파트 6·벙커 4·기관총좌 2·집 3), 14초 넘게 조용하면 조금씩 스스로 나온다(재진입 대기 20~60초). 감시탑 위에서는 모습이 보이고 다른 건물은 창가 총구 섬광만 보이며, 구조물이 무너지거나 죽으면 밖으로 나온다.

## 탈환전 모드 (`src/65_reclaim.js`)
- 로비 모드 ‘탈환전’: 플레이어와 AI(‘적 수’ 만큼의 동맹 AI)가 모두 한 편이라 서로 싸우지 않는다. 사격·포격·수류탄·불길·감시탑/구조물 사격·철조망 피해가 모두 `isAllyT()` 로 동맹을 가려낸다.
- 목표: 맵의 자경단을 전부 사살하면 승리(상단에 ‘남은 자경단 N / 전체’ 표시), 플레이어 병력이 전멸하면 패배. 자경단은 모든 팀의 적이라 항상 사격 대상이 된다.
- 자경단 배치(`genReclaimMilitia` / `genReclaimFill`): 구조물 거점(아파트·감시탑 80%, 그 밖 40%) + 도시마다 순찰 무리(8~15명)·저격/기관총 사수 고리 + 들판 무리로 맵 면적/45 명 정도(96×96 ≈ 210명)를 채운다. mafia 시드는 기존 배치를 그대로 쓰고 모자라면 채운다.
- AI: 기지 확장·원정을 하지 않고 경제·구매만 하다가 병력이 무리 수×1.2+4 이상이 되면 가까운 무리(다른 동맹이 가는 무리는 뒤로)로 출동한다. 먼저 무리의 사정권 밖(반경+17칸)에 집결하고 75%가 모이면 한꺼번에 돌입하며, 소탕 후 18초 뒤 다음 무리를 노린다. 자경단 우회 길찾기와 본진 위협 중단은 탈환전에서 꺼진다.
- 새 시드 `occupied`: 대도시 지도(Urban War 지형)를 자경단이 점령한 맵. 모드와 상관없이 도시마다 거점·순찰대·사수 고리가 배치된다.

## 툴팁 · 능력치 표시 (`src/03_util.js`)
- 상점(총기·폭발물)·건설 목록·무기고 표·구조물 강화 트리는 기본적으로 **능력치 한 줄**만 보여 주고, 설명문(`desc`/`info`)은 마우스를 올리면 뜨는 툴팁(`#tip`)으로 표시한다.
- 새 항목 추가: `WEAP`·`EXP`·`OB`·`VEH`·`UPT` 에 수치와 설명만 넣으면 능력치 줄이 자동으로 만들어진다(건물 설명은 `OBDESC`). 새 종류는 `tipReg('종류',(id,n)=>({t,col,stats:[[라벨,값]…],d,ex}))` 로 한 번 등록하고, 템플릿에는 `${tipStats('종류:id')}` / `${tipAttr('종류:id')}`(= `data-tip`)를 붙인다.
- 건물·차량 능력치 순서는 통일: 체력 | 주둔 | 피해(단일/광역) | 사거리 | 건설 | 재료. 건설 목록 카드는 이 6줄을, 툴팁은 같은 표 + 설명문을 보여 준다. 무기·폭발물도 같은 용어(피해·사거리·재료/가격)를 쓴다.
- 상점은 📦 보급 / 🔫 무기 / 💣 폭발물 / 📋 주문 내역 묶음으로 나뉘고, 무기고를 클릭하면 뜨는 메뉴에서도 무기·투척물을 +1/+5 로 바로 주문할 수 있다(상점과 같은 `shopAddWeapon`/`shopAddExp`).
